# Demostración — Centro de Control Interno

## Preparación

Antes de la reunión, confirme que el usuario de demostración tenga rol `CONTROL_INTERNO` y que existan datos UAT sin información sensible:

- Un radicado vencido.
- Un radicado por vencer.
- Un radicado resuelto dentro del término.
- Un radicado sin responsable.
- Un hallazgo abierto.
- Un plan pendiente.
- Un plan vencido.

## Recorrido sugerido

### 1. Ingreso

Entre al panel con el usuario de Control Interno y abra **Control Interno** en el menú.

Explique: “Esta vista permite revisar y hacer seguimiento. Control Interno no responde radicados”.

### 2. Resumen

Muestre el título **Centro de Control Interno** y el bloque **Qué debo revisar hoy**.

Explique que el sistema presenta máximo cinco acciones y pone primero las urgentes.

### 3. Indicadores y colores

Muestre un indicador verde, uno amarillo y uno rojo:

- Verde: dentro de lo esperado.
- Amarillo: conviene revisar pronto.
- Rojo: requiere acción inmediata.

### 4. Alertas

Abra **Alertas**, seleccione una alerta de prueba y explique el motivo, la dependencia y la acción sugerida.

No marque alertas reales como revisadas durante una demostración sin autorización.

### 5. Hallazgo de prueba

Abra **Hallazgos** y cree un registro UAT:

- Dependencia: Secretaría de Gobierno.
- Tipo: Soporte insuficiente.
- Nivel: Medio.
- Descripción: “Hallazgo UAT para demostrar el flujo de seguimiento de Control Interno”.
- Evidencia: “Documento de prueba sin datos personales”.
- Acción recomendada: “Completar el soporte y remitir evidencia”.

Muestre el mensaje de confirmación y explique que el hallazgo queda abierto.

### 6. Plan de mejora

Abra **Planes de mejora**, seleccione el hallazgo UAT y complete:

- Acción de mejora.
- Responsable de cumplirla.
- Fecha compromiso.
- Evidencia esperada.

Explique que la dependencia reporta avances y Control Interno verifica el cierre.

### 7. Dependencias

Abra **Dependencias** y compare cumplimiento, vencidos, hallazgos, planes pendientes y nivel de riesgo.

Use las frases: “requiere seguimiento” o “presenta buen cumplimiento”.

### 8. Informe

Abra **Reportes** y seleccione **Exportar informe de Control Interno**.

Muestre las hojas: Resumen, Alertas, Hallazgos, Planes de mejora, Dependencias, Radicados revisados y Diccionario.

### 9. Cierre

Reitere:

- Control Interno revisa y deja evidencia.
- Las dependencias siguen siendo responsables de responder al ciudadano.
- Las recomendaciones ayudan a priorizar, pero la decisión la toma la funcionaria.

## Checklist posterior

- Cerrar o identificar claramente los datos UAT creados.
- Confirmar que no se usaron datos sensibles.
- Guardar el informe solo en la ubicación institucional autorizada.
- Registrar observaciones de la funcionaria para el siguiente ajuste.
